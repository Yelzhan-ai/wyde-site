# WYDE — сайт

Одностраничный сайт бренда обуви для широкой стопы. Три языка (RU / KZ / EN), тест стельки, квиз «тип стопы», картинка для сторис, калькулятор полноты JIS и анкета «Первая тысяча».

## Что лежит в репозитории

| Файл | Что это |
|---|---|
| `index.html` | Весь сайт: вёрстка, стили, тексты и логика в одном файле |
| `apps-script.gs` | Код для Google Таблицы, в которую будут падать анкеты |
| `og.png` | Картинка-превью, которую показывают мессенджеры и соцсети, когда кто-то делится ссылкой |
| `README.md` | Эта инструкция |

Сейчас сайт работает в **демо-режиме**: анкета проходит все проверки и показывает экран успеха, но сохраняется только в браузере того, кто её заполнил. До тебя ответы не доходят. Чтобы начать собирать настоящие анкеты, подключи Google Таблицу (раздел 2).

## 1. Как выложить сайт на GitHub Pages и получить ссылку

1. Открой репозиторий на github.com и нажми вкладку **Settings** (шестерёнка справа вверху).
2. В левом меню выбери **Pages**.
3. В блоке **Build and deployment** в поле **Source** оставь **Deploy from a branch**.
4. В поле **Branch** выбери ветку, в которой лежит `index.html` (обычно `main`), рядом оставь папку **/ (root)** и нажми **Save**.
5. Подожди 1–2 минуты и обнови страницу. Вверху появится строка **Your site is live at** со ссылкой вида:

   `https://yelzhan-ai.github.io/wyde-site/`

   Эту ссылку и ставь в шапку профиля в Instagram, TikTok и Threads.

Если ссылка не появилась:

- На бесплатном тарифе GitHub Pages работает только для **публичных** репозиториев. Проверь: Settings → General → в самом низу Danger Zone → Change repository visibility → Public.
- Файл должен называться ровно `index.html` и лежать в корне, не во вложенной папке.

После любого изменения файлов сайт обновляется сам за 1–2 минуты.

Чтобы видеть, откуда пришёл человек, добавляй к ссылке метку: `…/wyde-site/?utm_source=instagram`, `?utm_source=tiktok`, `?utm_source=threads`. Она запишется в столбец «Откуда пришёл».

## 2. Как подключить Google Таблицу

Понадобится обычный аккаунт Google. Займёт около 10 минут.

**Шаг 1. Создай таблицу.** Открой [sheets.new](https://sheets.new) и назови таблицу, например «WYDE — первая тысяча».

**Шаг 2. Открой редактор кода.** В меню таблицы: **Расширения → Apps Script**. Откроется новая вкладка с редактором.

**Шаг 3. Вставь код.** Удали всё, что там написано. Открой в репозитории файл `apps-script.gs`, скопируй его целиком и вставь в редактор. Нажми значок дискеты **«Сохранить проект»**.

**Шаг 4. Опубликуй.** Справа вверху нажми **Развернуть → Новое развертывание**. Затем:

- нажми шестерёнку рядом с «Выберите тип» и выбери **Веб-приложение**;
- «Запуск от имени»: **От моего имени**;
- «У кого есть доступ»: **Все**;
- нажми **Развернуть**.

**Шаг 5. Разреши доступ.** Google попросит разрешение: **Предоставить доступ** → выбери свой аккаунт. Появится предупреждение «Приложение не проверено» — это нормально, потому что скрипт твой собственный. Нажми **Дополнительные настройки → Перейти на страницу … (небезопасно) → Разрешить**.

**Шаг 6. Скопируй адрес.** Появится **URL веб-приложения**. Он начинается с `https://script.google.com/macros/s/` и заканчивается на `/exec`. Скопируй его.

**Шаг 7. Вставь адрес в сайт.** Открой `index.html`, найди блок `const CONFIG` (поиск по странице: Ctrl+F) и вставь адрес в кавычки:

```js
sheetUrl: "https://script.google.com/macros/s/ТВОЙ_КОД/exec",
```

Сохрани изменение. На GitHub это делается так: открой файл → значок карандаша → внеси правку → зелёная кнопка **Commit changes**.

**Шаг 8. Проверь.**

- Открой скопированный адрес в браузере. Должно показать `{"ok":true,"service":"WYDE"}`.
- Заполни анкету на сайте. В таблице появится лист **WYDE** с шапкой и первой строкой.

Столбцы таблицы: Дата, Имя, WhatsApp, Instagram, Город, Пол, Длина левой стопы, Длина правой стопы, Ширина в пучках, Ширина пятки, Обхват в пучках, Обхват в подъёме, Ширина стельки, Стопа шире стельки (мм), Полнота JIS, Тип стопы, Где обувь проигрывает, Бренды и ширины, Голос: модель, Голос: цвет, Язык сайта, Согласие, Откуда пришёл.

Ответы всегда записываются по-русски, на каком бы языке человек ни заполнял анкету. Язык видно в отдельном столбце.

**Если позже поменяешь код скрипта:** Развернуть → Управление развертываниями → карандаш → Версия: **Новая версия** → Развернуть. Адрес останется прежним.

**Если отправка не удалась** (нет связи, ошибка скрипта): человек видит сообщение, а его ответы остаются в черновике. Если в `CONFIG` указан `whatsapp`, появляется кнопка «Отправить в WhatsApp» с уже заполненным текстом анкеты.

## 3. Памятка: что заполнить в CONFIG позже

Блок настроек находится в `index.html`, в самом начале скрипта:

```js
const CONFIG = {
  whatsapp: "",   // номер в формате 77001234567
  instagram: "",  // ссылка
  tiktok: "",
  threads: "",
  company: "",    // название ТОО для футера
  sheetUrl: "",   // URL Google Apps Script
  metaPixelId: "",
  tiktokPixelId: ""
};
```

| Строка | Что вписать | Что появится на сайте |
|---|---|---|
| `whatsapp` | Номер без плюса и пробелов: `77001234567` | Плавающая кнопка WhatsApp, иконка в футере, запасная кнопка «Отправить в WhatsApp» |
| `instagram` | Ссылку `https://instagram.com/имя` или просто `@имя` | Иконка Instagram в футере |
| `tiktok` | Ссылку или `@имя` | Иконка TikTok в футере |
| `threads` | Ссылку или `@имя` | Иконка Threads в футере |
| `company` | Название ТОО, например `ТОО «WYDE»` | Строка в футере и в политике обработки данных |
| `sheetUrl` | Адрес из шага 6 выше | Анкеты уходят в таблицу, демо-режим выключается |
| `metaPixelId` | Номер пикселя Meta (только цифры) | Подключается пиксель Meta: просмотр страницы и событие `Lead` при отправке анкеты |
| `tiktokPixelId` | ID пикселя TikTok | Подключается пиксель TikTok: просмотр страницы и событие `SubmitForm` |

Пустую строку не нужно удалять: пока в кавычках пусто, связанный элемент просто не показывается.

## 4. Как править сайт

**Тексты.** Все слова на трёх языках лежат в `index.html` в объектах `T.ru`, `T.kz` и `T.en`. Меняй текст внутри кавычек, названия слева от двоеточия не трогай. Если правишь фразу на одном языке, поправь её и на двух других.

**Заголовок первого экрана.** Это строки `h1a` и `h1b`. Два запасных варианта записаны в комментарии над первым экраном (поиск: «Варианты заголовка»).

**Фото основателей.** Положи снимок в репозиторий под именем `founder.jpg`. В `index.html` найди комментарий «ФОТО» и замени блок-заглушку на строку с `<img>`, которая там приведена.

**Свой домен.** Если сайт переедет на другой адрес, замени адрес в двух строках в начале `index.html`: `og:url` и `og:image`.

**Демо-анкеты.** Пока `sheetUrl` пустой, анкеты лежат в браузере под ключом `wyde_submissions`. Посмотреть их можно в консоли браузера (F12 → Console): `JSON.parse(localStorage.wyde_submissions)`.

## 5. Что стоит знать

- Факты в разделе «Длина ≠ ширина ≠ объём» приведены со ссылкой на статью Jurca и др., Scientific Reports, 2019. Перед запуском рекламы сверь формулировки с текстом статьи.
- Поле «Ширина стельки» в анкете необязательное: у части обуви стелька приклеена, и обязательное поле отсекло бы таких людей.
- Если человек вводит мерку в миллиметрах (например, 265), сайт сам переводит её в сантиметры (26,5).
- Калькулятор полноты считает по мужской таблице JIS: обхват для полноты D равен 222 + 0,6 × (длина в мм − 225), шаг между буквами 6 мм.
